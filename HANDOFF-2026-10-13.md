## Gotchas learned today (Claude-in-Chrome on Nexus)

- Keep the Chrome tab in the FOREGROUND. Background tabs freeze: screenshots time out and Save clicks silently do not register.
- A narrow Chrome window makes Nexus use a cramped mobile layout where the preview side panel covers the editor. Ask for a full-size window.
- The description editor only takes input in **View source** mode (the `[ ]` toggle); `form_input` on the hidden textarea shows "Mod saved" but nothing is stored. Type BBCode via the `type` action after select-all.
- The edit page sometimes shows "Failed to load mod details (403)"; reload once.
- After Save, verify on the PUBLIC page (the editor preview can lag). A browser "Leave site?" dialog means unsaved changes.
- Click Save by coordinates/ref only after a fresh screenshot; the button moves when the window size changes.

## UPDATE ~16:50 2026-10-13 - In-Game Playtest Bug Fix: Invalid Target on Guilt Trip, Public Scene & Compassion Burnout
- **Bug Identified (Matthew in-game test):** Guilt Trip, Public Scene, and Compassion Burnout showed "Invalid Target" on enemies and allies.
- **Root Cause:** When Claude originally wrote `hc_hustle.py`, it required `HasStatus('PANHANDLING_SHAME')` and `HasStatus('HC_HOMELESS_FATIGUE')` inside the engine's `TargetConditions`. Because enemies do not start combat with these statuses, the BG3 targeting cursor rejected player selection on every un-afflicted creature.
- **Fix Applied:**
  - Relaxed `TargetConditions` to standard `Character() and not Ally() and not Dead()` across all three spells so they can always be cast on any enemy.
  - Converted status interactions into powerful combo bonus effects:
    - **Guilt Trip:** Deals 1d6+CON base psychic damage. If the target is Socially Shamed, deals an additional 2d6 psychic damage and consumes shame.
    - **Public Scene:** WIS save or Frightened for 1 turn. If the target is Socially Shamed, duration extends to 2 turns and consumes shame.
    - **Compassion Burnout:** Deals 2d6 base psychic damage. If the target has Homeless Fatigue, deals an additional 2d6 psychic damage and ends fatigue.
- **Verification & Rebuild:** All 14 tests pass. `HomelessCalifornian.pak` rebuilt (`23,410,355` bytes) and installed locally to BG3 Mods. Backup saved in `work/installed-backups/HomelessCalifornian-post-invalid-target-fix-20261013-1650.pak`.
