## Gotchas learned today (Claude-in-Chrome on Nexus)

- Keep the Chrome tab in the FOREGROUND. Background tabs freeze: screenshots time out and Save clicks silently do not register.
- A narrow Chrome window makes Nexus use a cramped mobile layout where the preview side panel covers the editor. Ask for a full-size window.
- The description editor only takes input in **View source** mode (the `[ ]` toggle); `form_input` on the hidden textarea shows "Mod saved" but nothing is stored. Type BBCode via the `type` action after select-all.
- The edit page sometimes shows "Failed to load mod details (403)"; reload once.
- After Save, verify on the PUBLIC page (the editor preview can lag). A browser "Leave site?" dialog means unsaved changes.
- Click Save by coordinates/ref only after a fresh screenshot; the button moves when the window size changes.
