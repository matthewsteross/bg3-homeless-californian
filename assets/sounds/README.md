# Meme sound pack (joke audio, not wired in)

Generated sound effects and spoken lines for a joke mod. Every file in `meme/` is generated by one of the scripts in this folder. No downloaded, sampled or copyrighted audio is used.

Format: 16-bit PCM, mono, 44100 Hz WAV, peak-normalised to about -3 dBFS, 5 ms fades at both ends.

## Scripts

- `make_meme_sounds.py`: synthesises the sound effects with numpy (requires numpy only).
- `make_tts_lines.ps1`: speaks the lines with the default installed Windows voice via System.Speech (PowerShell 5 or 7).

## Sound effects (`meme/`)

| File | What it is |
|---|---|
| `airhorn.wav` | Three detuned square/saw voices stacked with a slight pitch drop and a tail, about 1.5 s. |
| `sad_trombone.wav` | Four descending notes with vibrato and a long final slide, about 3 s. |
| `boom.wav` | Low sine thud with a fast pitch drop, a noise crack and a reverb tail, about 1.5 s. |
| `boing.wav` | Springy up-and-down pitch sweep, about 1 s. |
| `dialup.wav` | Modem-style tone sweeps, an FSK warble and a hiss tail, about 3 s. |
| `error_beep.wav` | Two-note retro error chime, about 0.5 s. |
| `kazoo_fanfare.wav` | Short kazoo-like melody with buzz and vibrato, about 2 s. |
